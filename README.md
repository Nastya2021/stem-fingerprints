# Обробка відбитків пальців класичними методами

STEM-проєкт: два пайплайни обробки відбитків (SOCOFing), усі алгоритми
реалізовано вручну на NumPy. Порівняння стійкості до шуму, нерівномірної
яскравості та низького контрасту.

## Пайплайни
| Назва | Стадії |
|---|---|
| pipeline1 | розтягування контрасту → Оцу → Zhang-Suen |
| pipeline1_eq | гістограмне вирівнювання → Оцу → Zhang-Suen |
| pipeline2 | смуговий FFT-фільтр → Саувола → Zhang-Suen |

## Встановлення
```
python -m venv .venv
.venv\Scripts\activate        # Windows (Linux/Mac: source .venv/bin/activate)
pip install -r requirements.txt
```

## Дані
Датасет SOCOFing (Shehu, Ruiz-Garcia, Palade, James, 2018), ліцензія
CC BY-NC-SA. Деталі й джерело: `data/README.md`.
- `data/sample/` містить кілька зображень для швидкого запуску.
- Повна вибірка: розпакуйте архів у `data/` і запустіть


## Запуск
```
python main.py --pipeline pipeline2     # один пайплайн (або all)
python experiment.py                    # метрики → results/metrics.csv
python analyze.py                       # таблиця і графіки → results/analysis/
python -m pytest                        # тести
```
Усі параметри методів і рівні псування задаються в `config.json`,
код змінювати не потрібно.

## Структура
```
methods/      алгоритми (histogram, segmentation, morphology, frequency)
pipelines.py  збірка стадій у пайплайни
degrade.py    штучне псування зображень (seed фіксований)
metrics.py    MSE, PSNR, SSIM
main.py       обробка папки зображень
experiment.py обчислення метрик
analyze.py    зведена таблиця й графіки
tests/        автотести
experiments/  скрипти підбору параметрів
```

## Метрики
Еталон R — результат пайплайна на чистому відбитку. Метрики порівнюють
його з результатом на зіпсованому відбитку, тож вони вимірюють
стабільність, а не абсолютну правильність скелета.

## Відомі обмеження
- Оцу втрачає слабкі гребені (глобальний поріг).
- У пайплайні 2 по краях зображення (приблизно 7 пікселів) є шум, причину
  не з'ясовано.
- Гістограмне вирівнювання на цьому датасеті збільшує частку чорного
  та погіршує бінаризацію.
